# Миграция с Expo на Flutter

Flutter-приложение находится рядом с текущей Expo-реализацией, чтобы сравнивать
поведение двух версий до достижения функционального паритета.

## Принципы

- Expo остаётся эталонной работающей версией на время миграции.
- Функции переносятся вертикальными срезами: data client, repository, Riverpod,
  UI и тесты.
- ID слов, учебников и модулей не меняются.
- Новый код следует правилам из [ARCHITECTURE.md](ARCHITECTURE.md).
- Expo-код нельзя удалять до переноса пользовательских данных.

## Выполнено

- создан Flutter-каркас для Android, iOS и Web;
- подключены Riverpod, `go_router` и `PageView`;
- настроены VGV architecture и локальные packages;
- перенесён поиск по словарю;
- перенесена карточка слова;
- подключена SQLite/Drift реализация для Android и iOS;
- подключена HTTP JSON реализация для Web;
- настроен flavor `native` для Android и iOS;
- разделены platform assets;
- добавлены UI, repository и data client tests.
- перенесены настройки языка и темы с Expo-совместимыми ключами;
- локализован текущий интерфейс на русский, английский и арабский.
- перенесены 4 учебника и 31 модуль с исходными ID;
- добавлены списки слов, настройка и базовый flashcard-flow занятия.
- перенесены module overview, статистика и три уровня проверки знаний;
- прогресс сохраняется под Expo-ключом `learningProgress`.

## Совместимость

- версия Flutter-приложения остаётся `0.5.1+16` до следующего продуктового
  релиза;
- Android package: `com.altsaint.germanwordstrainer`;
- iOS bundle ID: `com.altsaint.germanwordstrainer`;
- словарь сохраняет существующие normalized IDs;
- Web сохраняет относительные пути `/lexicon/*`;
- native builds используют flavor `native`.

Подробности реализации словаря находятся в [LEXICON.md](LEXICON.md), команды
разработки и сборки — в [DEVELOPMENT.md](DEVELOPMENT.md).
